Extension parameter and coefficient types previously retained a `Fintype F` dictionary even for coordinate access and arithmetic. This made an enumeration prerequisite for compiling extension clients. Move raw parameters, nominal coordinates, reduction multiplication, powers and the inverse candidate into `Extension.Arithmetic`, with arithmetic requiring only `Ring F`.

Field certification now takes `Finite F`, `Fact (Nat.card F = P.q)` and irreducibility separately. Cardinality proofs use proof-local enumerators, while callers that explicitly supply `Fintype F` retain enumeration and cardinality compatibility APIs. The six concrete extensions retain their degrees, modulus coefficients and arithmetic; their cardinality certificates move out of parameter data. Canonical field operations still use the same raw implementations.

Regression coverage checks incorrect cardinality despite irreducibility, an infinite field with a true `Nat.card = 0` certificate, and iterated finite extensions without enumeration dictionaries. Raw-only integer and structure-free coordinate clients exercise the new import boundary. Documentation states that alternative coefficient algebra structures on the same type remain relative to the supplied dictionary.

Validation: full build with warnings as errors, full tests, style/import/documentation checks, and an axiom sweep of 9,921 declarations across 349 modules with no admitted or nonstandard dependencies. The native benchmark executable builds and all eight existing small extension workload checksums match the previously recorded baseline; this is functional evidence, not a performance comparison. Two independent statement/polish and adversarial reviews approved the exact patch. ArkLib #895’s full `validate.sh --axioms` gate also passes against this frozen source via a temporary path dependency: 11,456 declarations, 291 existing admitted dependencies, no new or nonstandard axiom debt, and all 19 other dependency records unchanged.
