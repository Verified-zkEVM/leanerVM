Add honest Boolean suffix-sum polynomials, their evaluation and degree identities, and explicit transport for high-first variable order. The suffix representation agrees as a polynomial with the pinned ArkLib round projection; its sharper degree bound uses the selected coordinate. The base algebra retains a commutative-semiring interface, including trivial semirings.

For #37 and [ArkLib #1](https://github.com/Verified-zkEVM/ArkLib/issues/1), following leanVM's sumcheck specification and [leanth #16 at `23929f8`](https://github.com/Verified-zkEVM/leanth/blob/23929f8c922cd4461ab22dbfaa6520f3ad23a3b2/Leanth/ProofSystem/ZeroCheck.lean#L3455). The existing dependency pins are preserved; upstream adoption of the residual transports will allow the compatibility adapter to be removed.
